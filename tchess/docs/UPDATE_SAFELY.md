# Как обновить, не потеряв ни одного игрока и ни одной задачи

## Что сделано в коде
1. **Миграции только добавляют.** Новые таблицы и колонки создаются через `CREATE … IF NOT EXISTS` /
   `ADD COLUMN IF NOT EXISTS`. Никаких `DROP`, `DELETE`, `TRUNCATE`, переименований. Это проверяет
   автотест `test/migrations-safe.test.js` — он упадёт, если кто-то добавит разрушающую миграцию.
2. **Каждая миграция — одна транзакция.** Сбой = полный откат, база остаётся как была. Если миграция не
   прошла, сервер **не запускается**, и Render оставляет прошлую рабочую версию.
3. **Снимок перед изменением данных.** Единственная миграция, которая пишет в существующие строки
   (выдача публичных ID игрокам), сначала копирует `users` в таблицу `bak_ГГГГММДДЧЧММ_users`.
   Хранятся 3 последние копии. Их список виден в Админ-меню → «База».
4. **Публичный ID не меняется.** Старый «T-CHESS-XXXXXX» (последние 6 символов id) сохраняется у каждого
   игрока; новый ID выдаётся только при редком совпадении.
5. **Нет молчаливого перехода на пустую базу.** Если на Render потерялась `DATABASE_URL`, сервер
   откажется стартовать (раньше он тихо уходил на пустые JSON-файлы).
6. **Рейтинг обновляется атомарно** (`rating = rating + N` прямо в базе): две партии, закончившиеся
   одновременно, больше не затирают друг другу результат.
7. **Задачи не «воскресают»**: стартовый набор сеется только при самом первом создании таблицы.

## Порядок обновления (5 минут)
1. **Сделайте копию базы** — любой из способов:
   - Neon: Branches → *Create branch* (мгновенный снимок, бесплатно) — самый простой;
   - или локально: `npm run backup` (нужен `DATABASE_URL` в `.env`), файл появится в `backups/`.
2. Проверьте, что база подключена: `npm run verify-db` — увидите число игроков и задач.
3. Запустите автотесты: `npm install && npm test`.
4. Задеплойте. В логах Render должны появиться строки `✅ Миграция 2…7` и
   `✅ Подключено к Postgres, схема актуальна.`
5. Откройте Админ-меню → «База» и сверьте числа игроков и задач с пунктом 2.

## Если что-то пошло не так
- Сервер не стартует с текстом про `DATABASE_URL` — проверьте переменную в Render → Environment.
- Хотите вернуть строки из копии: `npm run restore -- backups/файл.json` — **только добавляет**
  недостающее, ничего не перезаписывает и не удаляет.
- Откат кода на прошлую версию безопасен: новые колонки и таблицы старой версии не мешают.

## Во время турнира
Партии живут в памяти сервера. **Не деплойте во время турнира**: идущие партии будут отменены (рейтинг
не изменится, очки турнира за них не начисляются). Таблица очков хранится в базе и переживёт перезапуск.
